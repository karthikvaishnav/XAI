Main Points discussed in papers: LIME explains individual predictions by approximating the complex model locally using a simple, interpretable surrogate model. Input perturbations are used to observe how prediction changes, helping identify the most important features for a given prediction. The method is model-agnostic — applicable to any classifier or regressor — improving transparency, trust, and debugging of ML models. Experimental results demonstrate that local explanations significantly improve user trust and understanding compared to black-box model outputs.

Literature review:
8
The literature review shows that Explainable AI (XAI) has become a critical area of research due to the black-box nature of modern ML models. Foundational works such as LIME and SHAP have established widely accepted methods for local and global explanations. Multiple surveys highlight that visualization plays a key role in making explanations understandable to users. Visual analytics frameworks demonstrate that combining interactive visualizations with explanation techniques significantly improves user trust and conceptual understanding. The literature also emphasizes that interpretability is a human-centered problem. Recent studies in educational contexts show that explainable dashboards help non-expert users understand and trust ML systems. Most existing XAI tools are designed for researchers, creating a clear gap for a simplified, student-friendly XAI dashboard that this project addresses.

Research Gaps
13
Most existing XAI work focuses on individual explanation methods (SHAP or LIME alone) rather than integrated, end-to-end learning platforms.Existing XAI tools are designed for researchers or industry users, making them complex and unsuitable for students.No unified system combines data preprocessing, model training, evaluation, and explainability in a single interactive environment.Visual analytics XAI systems exist but are research-oriented and difficult to use in educational settings.Limited work on student-friendly, interactive XAI dashboards that support intuitive learning and conceptual understanding of ML models.

--- Slide 14 ---
Problem statement
14
Despite the rapid adoption of machine learning, most learning platforms focus mainly on model accuracy, offering little insight into how and why models make decisions. This lack of explainability causes ML models to appear as black boxes, making it difficult for students to connect theory with real-world behavior. Although XAI methods like SHAP and LIME exist, they are rarely integrated into interactive, student-friendly learning environments. This project proposes an integrated XAI dashboard that combines model training, evaluation, visualization, and explanation to improve conceptual understanding and hands-on ML learning for students.

--- Slide 16 ---
Proposed Solution
16
Our proposed system is an interactive Explainable AI (XAI) learning dashboard designed to help students understand how machine learning models make decisions. The system allows users to upload real-world datasets in CSV format and performs automatic preprocessing including handling missing values, encoding categorical variables, and feature scaling. Students can then select from multiple ML models such as Logistic Regression, Decision Tree, Random Forest, and SVM, and configure train-test splits to observe how these choices affect performance. A key component is the XAI layer, which integrates SHAP and LIME along with model-based interpretability methods to provide both global explanations (overall feature importance) and local explanations (feature contributions for individual predictions). The interactive dashboard presents evaluation metrics such as accuracy, precision, recall, F1-score, and confusion matrix in a student-friendly manner. Advanced visualizations including 2D/3D plots and decision boundaries are included to enhance conceptual understanding. The overall goal is to transform ML education from a formula-driven process into a visual, interactive, and explanation-driven learning experience.

--- Slide 19 ---
Methodology / Algorithms
19
Data Upload and Preprocessing	Students upload real-world CSV datasets. The system performs automatic preprocessing including handling missing values, encoding categorical variables, and feature scaling. Feature selection is also supported, allowing users to observe how input choices affect model performance.ML Model Training	Students select from Logistic Regression, Decision Tree, Random Forest, or SVM. The system trains the chosen model on the preprocessed data and evaluates it using accuracy, precision, recall, F1-score, and confusion matrix.XAI Explanation – SHAP and LIME	SHAP generates global feature importance across the full dataset and local Shapley-value attributions for individual predictions. LIME approximates the model locally using perturbed samples to identify which features drive each specific prediction.Visualization and What-If Analysis	The dashboard renders 2D/3D feature plots, decision boundaries, and SHAP/LIME charts. Students can modify input feature values interactively and observe how the model's prediction changes, enabling deeper conceptual understanding.

--- Slide 23 ---
Data flow diagram
Data collection starts in the Data Input module, where the student uploads a CSV dataset through the dashboard interface.The collected raw data is sent to the Preprocessing module, where missing values are handled, categorical variables are encoded, and features are scaled.The processed data is stored and passed to the Model Training module, where the selected ML model (Logistic Regression, Decision Tree, Random Forest, or SVM) is trained.The trained models generate predictions for new incoming data, which are forwarded to the Explanation module.In the explanation stage, SHAP and LIME compute global and local feature attributions.If abnormal behavior is detected, the results are sent to the Output module.The output module updates the dashboard, stores logs, and sends real‑time alerts to notify the user.

--- Slide 24 ---
Control flow diagram
System starts with data upload, where the student uploads a CSV dataset via the dashboard.The collected data goes to preprocessing and feature engineering, where missing values are handled, encoding and scaling are applied.The processed data is passed to the model, where the selected ML model is trained on the processed data.The model performs prediction and evaluation on the new incoming data.The predicted values are compared with actual values in the explanation stage.If the result is normal, the system displayed on the dashboard for student exploration.If an anomaly is detected, the system re-runs prediction and updates the explanation interactively.If the evaluation shows poor accuracy or model failure, the system goes to model selection and retraining, choose different parameters, and retrain.The process repeats continuously for the different datasets or models, making the dashboard a flexible learning tool.
